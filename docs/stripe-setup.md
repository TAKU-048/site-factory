# Stripe 設定手順（月額ホームページ制作・管理サービス）

作成：2026-10-21。決定済みの条件（クレジットカードの毎月自動決済のみ／公開日から課金・初月は日割り・翌月以降は月初／最低12か月）を、プログラムを書かずにStripeの管理画面だけで実現する手順。
Stripeの画面の名前や場所は変わることがあるため、実際の画面と違う場合は画面の表示を優先する。

## 手数料（2026-10-21 確認）

- カード決済：1件ごとに3.6%（通貨換算がある場合は追加2%）
- Billing（サブスクリプション）：0.7%
- 月額10,560円（税込）なら1件あたり約454円／月
- 出典：https://stripe.com/jp/pricing

## 1. アカウント登録（本人の作業）

1. https://dashboard.stripe.com/register から登録する。
2. 事業者情報を入力する。
   - ウェブサイト：https://tk-creative.org/web-subscription.html
   - 特定商取引法に基づく表記：https://tk-creative.org/tokushoho.html（「要決定」の箇所を埋めて公開してから登録する）
   - 商品の説明：ホームページの制作と、公開後の管理・保守の月額サービス
3. 本人確認書類と入金先の銀行口座を登録する。
4. 2段階認証を必ず設定する。

## 2. 商品を登録する

商品カタログで次の2つを作る。

| 商品名 | 価格 | 種類 |
|---|---|---|
| 月額ホームページ制作・管理 | 10,560円（税込） | 継続（毎月） |
| ページの追加 | 22,000円（税込） | 一回限り |

## 3. 顧客ポータルを設定する（カード登録・変更用）

設定済み（2026-10-21）。ログインリンク：https://billing.stripe.com/p/login/3cI9AT93z2K6cxw5Jmgbm00

設定 → Billing → カスタマーポータル

- 「支払い方法の更新」をオン
- 「請求書の履歴」をオン
- 「サブスクリプションのキャンセル」はオフ（最低12か月の精算があるため、解約はメールで受け付ける）
- ノーコードのログインリンクを有効にし、URLを控える（お客様はメールアドレスで届く確認コードを使ってログインする）

## 4. 契約が成立したとき（カード登録・まだ課金しない）

1. 顧客 → 顧客を作成：お客様の会社名・メールアドレス（申込フォームと同じもの）
2. お客様に、承諾メールと一緒に顧客ポータルのログインリンクを送り、カードを登録してもらう。
3. 顧客の画面で、カードが「デフォルトの支払い方法」として登録されたことを確認する。
4. カード番号を電話やメールで聞かない。こちらで代わりに入力しない。

## 5. 公開日（課金を始める）

1. 顧客 → 該当のお客様 → サブスクリプションを作成
2. 商品：月額ホームページ制作・管理
3. 開始日：公開日
4. 請求サイクルの起点：翌月1日
5. 日割り（比例配分）：オン → 公開日から月末までの日割り額が、その日に請求される
6. 支払い：デフォルトの支払い方法で自動的に請求
7. メモ欄に「最低利用期間：公開日〜12か月後の月末」を書いておく

## 6. 解約の申し出があったとき

- 最低利用期間を過ぎている：サブスクリプションを「期間の終了時にキャンセル」にする（月末で終了）。
- 最低利用期間内（お客様都合）：残りの期間の月額料金を、一回限りの請求書で請求したうえで、月末で終了する。

## 7. カード決済に失敗したとき

- 設定 → Billing → 支払いの再試行：自動の再試行をオン
- 失敗した支払いをお客様にメールで知らせる設定をオン
- 公開を止めるまでの期間は利用規約で「要決定」のまま。決めてから運用する。

## まだ決めていないこと

- 決済失敗が続いた場合に公開を止めるまでの期間（利用規約 第4条）
- お客様の入金・解約を制作システムの顧客管理に自動でつなぐか（お客様が増えてから検討）
